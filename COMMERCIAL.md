# Purchasing, Licensing, and Support

NexusKestrel is proprietary hardware and firmware from AutomataNexus, LLC. It is not
open source. The firmware is licensed with each controller under the
[EULA](EULA.md).

## How it is supplied

| Option | What you get |
|---|---|
| **Installed** | Controllers supplied, installed, integrated, and commissioned by AutomataNexus controls technicians or an authorized partner, with the NexusEdge Console subscription. |
| **Integrator** | Controllers and commissioning support for controls contractors who install and service them on their own projects. |
| **Takeover** | A Kestrel placed as the supervisor of an existing building automation system whose front end is obsolete, unsupported, or dead, reading and commanding the existing field controllers over their own protocols, with no rip-and-replace. |

## Included with every controller

- the firmware license for that controller;
- signed over-the-air firmware and security updates for the supported release line;
- the integration sheet (BACnet objects, EDE export, Modbus map) for your BMS team.

## NexusEdge Console

Trends, alarms, graphics, commands with read-back, alarm e-mail, and fleet updates are
provided by the NexusEdge Console under a subscription. Controllers keep running
locally without it.

## Support tiers

| Tier | Description |
|---|---|
| **Standard** | E-mail support, over-the-air updates |
| **Professional** | Priority response, remote diagnostics, sequence changes |
| **Enterprise** | Response-time commitments, on-site service, custom protocol and sequence development |
